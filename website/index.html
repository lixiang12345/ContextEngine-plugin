让 AI 编程 Agent
一次就找对代码

ContextEngine 是可移植的 Augment 级代码库上下文引擎：把关键词、符号、路径、语义向量、依赖图与提交历史融合成一次检索，再按 token 预算打包成带路径与行号的可验证上下文——让 Agent 少花 token 盲目 grep，多花回合改对代码。

为什么需要它

Agent 的 token，不该花在盲目 grep 上

大多数编程 Agent 靠反复 grep / find 摸索大仓库——每一轮工具调用都在消耗上下文窗口，却仍然经常漏掉真正相关的文件。

轮次浪费

一次任务动辄十几次 grep / 读文件调用，真正用于写代码的回合被检索占满。

上下文噪声

整文件塞进上下文窗口，重复、无关的内容稀释了模型对关键代码的注意力。

召回盲区

关键词匹配不懂同义改写，纯向量检索又找不准精确符号——单一信号总有盲区。

ContextEngine 的做法

一次调用完成查询理解 → 多信号并行召回 → 融合重排 → 依赖图扩展 → MMR 打包，返回带路径、行号、来源与检索轨迹的紧凑上下文。Agent 先调 codebase-retrieval，再动手编辑——而不是先 grep 十次。

工作原理

六级检索管线，信号互补

复刻让专有检索模型有效的系统模式:understand → retrieve → fuse → rerank → expand → pack。任何单一通道失误，都会被其余通道兜住。

查询理解

抽取标识符与路径线索，判定意图(symbol / path / concept / history)，扩展检索词。

多信号召回

PostgreSQL FTS(tsvector+GIN)、符号表、路径匹配与 pgvector 语义 KNN 并行执行。

RRF 融合

Reciprocal Rank Fusion 合并各通道排名，对单通道错误保持鲁棒。

代码感知重排

符号、路径、标识符重叠与语言特征打分；可选接入 /v1/rerank 神经重排。

依赖图扩展

沿 import / symbol 图把候选周边的相关文件带进结果。

MMR 打包

按路径做多样性去重，在 token 预算内输出带行号的证据块。

语义通道可选：不配 embeddings 时以 BM25-only 模式离线运行，依旧可用；每次检索都返回可复现的 trace(意图、通道、降级项、token 用量)。

核心能力

一个小而完整的检索层

不是又一个向量数据库 demo——而是覆盖索引、检索、打包、观测与团队协作的完整组件。

词法检索，数据库级扩展

PostgreSQL tsvector + GIN 索引，过滤在数据库侧完成，不把全量内容拉进进程内存。

符号精确检索

声明级符号表支持精确与前缀匹配——"找 processPayment" 这类查询不再依赖向量的运气。

语义检索(可选)

任何 OpenAI 兼容 embeddings 端点即插即用；pgvector 余弦 KNN + HNSW，两阶段只对候选精排。

融合 + 代码感知重排

RRF 融合多通道，再按符号 / 路径 / 标识符重叠 / 语言特征重排；可选神经重排第二阶段。

MMR 上下文打包

按路径多样性去重，在 token 预算内选块；raw / extractive 两种打包策略。

符号 / import 依赖图

检索命中后沿依赖图扩展相关文件，把“改这里还要看哪里”一并带出。

多根工作区

代码仓 + 文档仓 + 额外目录进同一个索引(CONTEXTENGINE_EXTRA_ROOTS)，一次检索全覆盖。

提交血缘

近期 git 历史作为可检索块入索引，“这段逻辑最近为什么改” 也能被召回。

Watch 增量索引

文件哈希增量 + 防抖重建；MCP 模式默认监听工作区，编辑后下一次检索即是新代码。

可复现检索轨迹

每次响应携带 intent、参与/降级通道、候选→打包数量、token 预算与索引 generation。

Augment 兼容忽略规则

内置智能过滤 + .gitignore + .augmentignore(含 ! 反选)+ .contextengineignore。

团队索引快照

版本化、校验和验证的文件系统 / S3 兼容快照，导出、导入、复制与定时任务齐备。

运维仪表盘

HTTP 服务自带 /dashboard：工作区状态、索引任务、延迟 p95、错误率与在线检索探针。

接入方式

四种形态，同一个检索核心

MCP 插件、命令行、带鉴权的 HTTP 服务、TypeScript 库——按你的 Agent 架构任选，检索质量一致。

MCP · STDIO

Claude Code / Cursor 一行接入

暴露 Augment 兼容的 codebase-retrieval 等六个工具，默认监听文件变更。

# 安装后注册到 Claude Code
claude mcp add contextengine -- contextengine-mcp

# 常用环境变量
export CONTEXTENGINE_ROOT=/path/to/repo
export CONTEXTENGINE_AUTO_INDEX=1
CLI

索引、搜索、打包一条命令

适合脚本、CI 与快速验证，支持 --json 结构化输出。

contextengine index
contextengine search "how is rate limiting implemented"
contextengine context "Add retry logic to the payment webhook"
contextengine status
HTTP · REMOTE MCP

远端 IDE 与团队服务

Bearer 鉴权工作区同步、后台索引任务、SSE 进度、Remote MCP 与运维仪表盘。

export CONTEXTENGINE_HTTP_API_KEY="$(openssl rand -base64 32)"
contextengine-http
# GET /health · GET /openapi.json
# Dashboard: http://127.0.0.1:8787/dashboard
LIBRARY · TYPESCRIPT

嵌入你自己的 Agent 循环

类型完整的库 API，索引、检索、打包、统计全部可编程。

const engine = ContextEngine.open({ root: "/repo" });
await engine.index();
const hits = await engine.search({ query: "auth middleware" });
const packed = await engine.getTaskContext({ task: "…" });

诚实对比

vs Augment Context Engine

我们是开放、可移植的构建组件，不是完整的商业上下文平台——两者的取舍如下，不夸大。

能力ContextEngineAugment
开源 / 自托管 / 离线可用 ✓ MIT，BM25-only 可完全离线 ✗ 商业产品
MCP + 混合检索 ✓ stdio + Remote MCP，多信号融合 ✓ 本地 + 托管 MCP
自训练代码检索模型 ✗ BYO OpenAI 兼容 embeddings ✓ 成对训练的专有模型
多源内容(Git 托管 / 网站) ◐ 连接器 SDK + GitHub / GitLab / Bitbucket / 静态网站 ✓ 打包的企业级连接器矩阵
超大 monorepo 规模 ◐ PostgreSQL 架构，中型仓库已验证 ✓ 生产级 monorepo 索引
成本与所有权 ✓ 基础设施自有，仅 embedding API 按用量 ◐ 产品订阅(含免费查询层)

设计原则第五条就是“诚实的范围”：我们优化所有权与可改造性，不声称全面对齐 Augment。逐项差距分析见 COMPARISON.md 与 对齐审计。

快速上手

三步跑通第一次检索

只需要 Node.js ≥ 22.5 和一个带 pgvector 的 PostgreSQL(仓库内置 Docker Compose)。

准备数据库

使用仓库自带的本地 pgvector 服务，或指向任意已有 PostgreSQL。

git clone https://github.com/lixiang12345/ContextEngine-plugin.git
cd ContextEngine-plugin && npm install && npm run build
npm run db:up
export CONTEXTENGINE_DATABASE_URL=postgresql://contextengine:contextengine@127.0.0.1:54329/contextengine

为工作区建索引

索引存入 PostgreSQL，以工作区绝对路径为命名空间——一个库可安全容纳多个仓库。

npx contextengine-plugin index /path/to/your/repo

搜索，或直接为任务打包上下文

无 API key 时以 BM25-only 模式运行；配置 OPENAI_API_KEY 即升级混合语义检索。

npx contextengine-plugin search "stripe payment webhook"
npx contextengine-plugin context "Add logging to payment requests"

把 Augment 级检索，装进你自己的 Agent

完整的安装、配置、MCP / HTTP 接入与故障排查，都在使用手册里。全部开源，MIT 协议，随时可以读源码。
